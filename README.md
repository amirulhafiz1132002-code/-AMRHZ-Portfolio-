# 🧠 AMRHZ-Portfolio: Auto AI Builder System

Ekosistem bersepadu untuk membina dan menggerakkan sistem AI automatik menggunakan kerangka kerja terdesentralisasi.

## 🚀 Seni Bina Teras (Modular)
- 📂 `backend/` (Python): Saluran algoritma & API.
- 📂 `frontend/` (JS/HTML/CSS): Pemantauan telemetri.
- 📂 `memory/`: *Persistence layer* untuk memori AI.
- 📂 `tests/`: Persekitaran verifikasi automatik.

## 📊 Telemetry & Dashboard
1. `AMRHZ-Ai-system.html` – Platform utama.
2. `About.html` – Falsafah reka bentuk.
3. `analytics.html` – Pemantauan prestasi.
4. `landing_pages.html` – Halaman pengenalan.

## 🛠️ Ringkasan Teknologi
- **AI Core**: OpenAI API
- **Backend**: Python
- **Frontend**: JS, HTML5, CSS3
- **Validation**: YAML Testing
