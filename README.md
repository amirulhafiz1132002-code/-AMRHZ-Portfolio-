# 🚀 AMRHZ Portfolio

Welcome to **AMRHZ Portfolio** — a personal dashboard-style web project built to showcase identity, ideas, and interactive command-based navigation.

---

## 🧠 Concept

This project is not just a normal portfolio.

It is designed as a **dashboard system** where users interact using command-style buttons, creating a more dynamic and futuristic experience.

---

## ✨ Features

- ⚡ Interactive dashboard interface
- 🧭 Command-based navigation system
- 🔗 Routing between pages (index → dashboard)
- 🎨 Custom UI design (HTML, CSS, JavaScript)
- 📂 Structured asset management
