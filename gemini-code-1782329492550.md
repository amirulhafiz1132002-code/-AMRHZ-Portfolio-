## 📂 Core Architecture Breakdown

The ecosystem is built out as a modular monorepo structure, ensuring clear separation of concerns across interface, intelligence, and system automation layers:

### 1. 🧭 AMRHZ Portfolio (The Interface Hub)
*   **Status:** 🟡 Active Development (Phase 1 Foundation)
*   **Tech Stack:** TypeScript, HTML5, CSS3, JavaScript
*   **Key Design:** A command-style interactive dashboard UI optimized for sub-1-second loading times. Features a programmatic page router designed to connect directly with the downstream RAG pipelines.

### 2. 🧠 AP1 Core (The AI Automation System)
*   **Status:** 🟡 Phase 1: Backend Setup
*   **Tech Stack:** Node.js, Express.js, Python, OpenAI Core, Vector DBs (Pinecone/Weaviate)
*   **Architecture Pattern:** 
    *   `/backend` → Main server configuration and processing hooks.
    *   `/api` → Secure application routing layers.
    *   `/brain_project` → Dedicated internal block hosting customized system logic and context rules safely separated from public wrappers.

### 3. ⚙️ AP1 Bash Toolkit (Infrastructure Automation)
*   **Status:** 🟡 Development
*   **Tech Stack:** Bash / Shell Scripting
*   **Purpose:** Handles system-level environment initializations, automated task scheduling, and quick-start environment routines.
